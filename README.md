# Banaras Rush

A Varanasi-inspired 3D driving game that runs in the browser, built with Three.js. It is designed to work on phones.

You drive an auto-rickshaw through the old city, pick up passengers, drop them at the ghats and temples, and honk your way past traffic and cows.

## Play

Open `index.html` in a browser, or host the repository with GitHub Pages (Settings, Pages, deploy from the `main` branch).

## Controls

| Input | Touch | Keyboard |
| --- | --- | --- |
| Drive | Hold one finger | W / Up |
| Steer | Drag left or right | A / D |
| Speed up | Drag up | W |
| Brake and reverse | Drag down | S / Down |
| Honk | Tap a second finger | Space / H |

## Current state

This is a first sample. It has an old-city grid, the Kashi Mandir temple, a clock tower, ghats and a river, AI traffic that turns at junctions, cows, a minimap and a passenger drop mission.

## Notes

All names, models and layout are original. The project does not use assets from other games.

## Assets and credits

- Vehicle models in `assets/models/`: [Kenney Car Kit](https://kenney.nl) (CC0). Licence in `assets/models/KENNEY-LICENSE.txt`.
- `assets/models/roads/`: street props from [Kenney City Kit Roads](https://kenney.nl) (CC0).
- `assets/models/people/`: pedestrians built from a low-poly human model supplied by the project owner (`tools/make_peds.py`).
- `assets/models/moto.glb`, `scooter.glb`, `auto_user.glb`: generated with Gemini by the project owner. `cow_*.glb` are built from a cow model supplied by the owner (`tools/make_cows.py`).
- `assets/models/auto_user.glb` (see above): auto-rickshaw generated with Gemini by the project owner.
- `assets/models/auto_green|blue|black.glb`: generated by the Python tools in `tools/`.
- The game loads the models over HTTP, so open it through GitHub Pages or a local server (`python3 -m http.server`), not by double-clicking the file. If a model fails to load, the old box vehicles are used instead.
- Shadows turn on automatically on capable devices. Force them with `?shadows=1` or `?shadows=0` at the end of the URL.

## Generating models with Python

`tools/glbkit.py` is a small numpy-only toolkit that builds low-poly models and writes `.glb` files. `tools/make_auto.py` uses it to build the auto-rickshaws (`assets/models/auto_*.glb`). Run `python3 tools/make_auto.py preview.png` to also write a preview image (needs matplotlib).

## Sound

All audio is synthesised in the browser (Web Audio), so there is nothing to download: put-put auto engine that follows speed, road and tyre noise, horns for every vehicle type (louder and panned by distance), cow moos, pickup chime and cash sound, city ambience (temple bells, birds, distant horns) and a soft sitar/tabla/tanpura background loop. The round button under the minimap cycles music + effects, effects only, and off (remembered between visits).

## School campus
`assets/models/school_campus.glb` is the Hyderabad Chhatwara school campus model (V14), converted by `tools/make_campus.py` (Z-up to Y-up, parts merged per material, origin at the gate). It stands on the block at x −90..−54, z 24..42, with the gate facing the z=48 road. Walls, rooms and tree trunks are solid; the courtyard is open. It is also a mission drop-off.
